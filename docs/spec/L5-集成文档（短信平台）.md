# 短信平台 · L5 集成文档

> 描述功能之间的调用关系、共享数据读写与事务边界。这是把散点功能文档「拼成系统」的装配图。

## 1. 调用关系

| 触发功能 | 被调功能/动作 | 说明 |
| --- | --- | --- |
| 充值 | 更新账号余额 + 写流水 | 同一事务 |
| 发送短信 | 校验账号 → 扣减额度 → 调通道 → 写记录 | 扣额度与写记录同事务，调通道可异步（AI建议） |
| 删除账号 | 校验发送记录 | 不做物理删除，仅逻辑删除 |

## 2. 共享数据读写

| 表 | 谁写 | 谁读 |
| --- | --- | --- |
| sms_account | F1、F2 | F2、F3 |
| sms_recharge | F2 | F2 |
| sms_send_record | 发送服务 | F3、F5 |

## 3. 事务边界

| 场景 | 边界（AI建议） |
| --- | --- |
| 充值 | 余额更新 + 流水写入 必须原子 |
| 发送 | 额度扣减 + 记录创建 同事务；调用第三方为不可回滚操作，需补偿/对账 |
| 删除账号 | 仅逻辑删除，单表操作 |

## 4. 第三方对接

- 统一接口 ISmsProvider（AI建议）：
| 方法 | 说明 |
| --- | --- |
| Send | 发送短信 |
| QueryBalance | 查询余额 |
| QueryStatus | 查询发送状态 |

- 各服务商实现（与 L1 `provider_type` 枚举对齐）：AliyunSmsProvider / TencentSmsProvider / MengwangSmsProvider / HttpCustomSmsProvider。
- 失败重试策略：最多 3 次，指数退避（AI建议）。
- 状态一致性：回调优先，定时对账兜底（AI建议）。

## 5. 数据一致性保障

| 风险 | 措施 |
| --- | --- |
| 余额并发丢失更新 | 行锁 + 事务 |
| 第三方调用超时 | 记录中间态 + 定时补偿 |
| 重复提交充值 | 充值单号唯一约束 |
| 状态不同步 | 回调 + 定时对账 |

## 6. 依赖全景

```
F1 账号管理 ──┬──> F2 充值（读账号、写余额/流水）
              └──> F3 记录（读账号、读记录）
F2 充值 ──────────> sms_account.balance
F3 记录 ──────────> F5 统计报表
发送服务 ─────────> ISmsProvider（第三方通道）
```
